# MPEI Student App (backend)

Серверная часть мобильного приложения для студентов **НИУ МЭИ**  
(расписание + оценки из системы БАРС)

## Основные возможности API

- Авторизация через логин/пароль системы БАРС  
- Получение расписания для группы на заданный период  
- Получение оценок студента (по семестрам, с детализацией заданий)  
- Хранение и обновление данных в MongoDB  
- Периодический парсинг данных из БАРС 
- Автоматическая документация Swagger 

## Технологии

- **Фреймворк** — FastAPI  
- **Валидация данных** — Pydantic  
- **База данных** — MongoDB (асинхронный драйвер motor)  
- **Сервер** — Uvicorn  
- **Конфигурация** — pydantic-settings + .env
